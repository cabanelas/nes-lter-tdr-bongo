# tdr-nes-bongo

STAR-ODDI DST centi-TD time-depth recorder (TDR) files collected during Bongo net tows for NES-LTER 
zooplankton Bongo and/or ring net tows conducted during Northeast U.S. Shelf Long-Term Ecological Research (NES-LTER) Transect cruises, ongoing since 2017

TDR data available for the following cruises: EN706, EN687, EN657, EN655, EN649, EN617, AT46, AR77, EN644, EN627, EN608
no TDR data for the following cruises: - EN661, AR63*, AR38, AR32, EN715, EN695
CTD data available for: EN668 and EN706

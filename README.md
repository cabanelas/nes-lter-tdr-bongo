# tdr-nes-bongo

STAR-ODDI DST centi-TD time-depth recorder (TDR) files collected during Bongo net tows for NES-LTER 
zooplankton Bongo and/or ring net tows conducted during Northeast U.S. Shelf Long-Term Ecological Research (NES-LTER) Transect cruises, ongoing since 2017

TDR data available for the following cruises: EN706, EN687, EN657, EN655, EN649, EN617, AT46, AR77, EN644, EN627, EN608

no TDR data for the following cruises: - EN661, AR63*, AR38, AR32, EN695

need to update EN715 does have TDR data

CTD data available for: EN668 (no tdr) and EN706

# Protocol

## Pre-deployment
- In SeaStar program, go to Wizards -> Connection wizard
- Insert TDR into shuttle; double click the COM port that turns green;  follow prompts/instructions
- First time, may need to go to “Program and Start Recorder”. Set measurement interval to 1 sec.
- For subsequent tows: Select "Restart recorder with the same sampling interval" but check sampling interval 
- Suggested start time will be 6 mins from now, which is probably fine
- Wait for it to do it thing, remove TDR, then close the window that popped up
- Close connection wizard
- Insert TDR into rubber sleeve
- Put plastic screw through hole right above TDR, screw nut on hand tight
- Put rubber sleeve into metal sleeve and put small metal bolt through loop made by wire
- Tighten nut until against sleeve, but no need to make really tight

TDR attached to Bongo frame

## Offloading
- Remove TDR by taking off the small bolt going through the wire loop, and remove from rubber sleeve
- In SeaStar program, go to Wizards -> Connection Wizard
- Insert TDR into shuttle, follow prompts/instructions- Click Yes when asked to retrieve recorder data
- After offload is finished, Click Disconnect Recorder in the wizard window
- In the window with the plot, click the save button (image of floppy disk)
- Add on to the end of the existing file name (DO NOT DELETE IT) the Cruise number (e.g. EN###), LTER station (e.g. L5), and sequential CTD cast # but with a B (e.g. B5)
- Save to the appropriate cruise folder in the "SeaStar Data" folder on desktop
- Back in the SeaStar window, click the Excel export button to save, save the same way as above and in same folder
- Close little window with the plot (not the whole SeaStar window)
- Click “Disconnect” to put TDR in sleep mode until next tow.
